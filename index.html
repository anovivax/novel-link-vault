GitHub Token ถูกเก็บเป็น Secret บน Cloudflare Worker ไม่เก็บในหน้าเว็บหรือในลิงก์แชร์ แต่ลิงก์แชร์เป็นกุญแจสำหรับอ่านและแก้ไขข้อมูลได้ ผู้ที่ได้รับลิงก์จะใช้งานคลังนี้ได้ทั้งหมด ห้ามแชร์สาธารณะ
หากขึ้น 404 หลังเชื่อม ให้ตรวจการตั้งค่า GH_OWNER, GH_REPO, GH_BRANCH และสิทธิ์ Contents บน Worker
